# Enterprise Data Warehouse Project Overview

## Introduction

The Enterprise Data Warehouse project demonstrates the design and implementation of a modern dimensional data warehouse for a multi-branch retail organization. The project covers the complete data lifecycle including data generation, ETL processing, dimensional modeling, SQL analytics, and interactive Power BI dashboards.

---

## Business Objective

The objective of this project is to transform raw transactional sales data into a centralized analytical repository that enables business users to monitor sales performance, profitability, customer behavior, employee productivity, and operational efficiency.

---

## Project Components

- Synthetic data generation using Python
- Staging layer for raw data
- Dimension tables
- Fact table
- Star Schema design
- SQL ETL process
- Business intelligence dashboards using Power BI
