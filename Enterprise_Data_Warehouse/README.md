# 🏢 Enterprise Data Warehouse Project

## 📌 Project Overview

This project demonstrates the design and implementation of a complete Enterprise Data Warehouse using dimensional modeling principles. The solution covers the entire data pipeline from synthetic data generation to ETL processing, star schema design, SQL analytics, and interactive Power BI dashboards.

The project simulates a multi-branch retail enterprise and provides business insights into sales performance, customer behavior, employee productivity, and profitability.

---

## 🎯 Objectives

- Build an enterprise-grade dimensional data warehouse
- Design a Star Schema for analytical reporting
- Perform ETL from staging tables into dimension and fact tables
- Generate synthetic enterprise datasets using Python
- Develop interactive Power BI dashboards
- Enable business decision-making through data visualization
