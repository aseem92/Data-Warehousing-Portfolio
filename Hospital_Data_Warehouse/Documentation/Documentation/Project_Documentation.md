# Hospital Risk Analytics System Documentation

## Project Objective

The objective of this project is to analyze hospital operational data and identify risks using SQL and Power BI. The dashboard helps hospital management monitor patient activity, doctor performance, complaints, and admissions.

---

# Technology Stack

- Python
- MySQL
- SQL
- Power BI
- Git
- GitHub

---

# Database Tables

## Patients
Stores patient demographic information.

## Doctors
Stores doctor information and department details.

## Patient Visits
Contains patient consultation history.

## Admissions
Stores patient admission records.

## Complaints
Contains complaints submitted by patients.
