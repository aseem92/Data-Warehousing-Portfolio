# Hospital Risk Analytics System

## Overview

This project demonstrates an end-to-end Hospital Risk Analytics solution built using Python, MySQL, SQL, and Power BI. The project focuses on analyzing hospital operations, monitoring patient activities, identifying operational risks, and presenting actionable insights through interactive dashboards.
