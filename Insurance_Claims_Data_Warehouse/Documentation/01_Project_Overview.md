# Insurance Claims Data Warehouse

## 📌 Project Overview

The Insurance Claims Data Warehouse is an end-to-end Business Intelligence and Data Warehousing project designed to transform raw insurance data into an analytical repository for reporting and decision-making.

The project demonstrates the complete ETL lifecycle, dimensional modeling, SQL-based analytics, and Power BI dashboard development using a MySQL Data Warehouse.

---

## 🎯 Project Objectives

- Build a centralized Insurance Claims Data Warehouse.
- Design a dimensional model using Fact and Dimension tables.
- Automate ETL using Python.
- Store analytical data inside MySQL.
- Develop an interactive Power BI dashboard.
- Generate business insights using SQL.

---

## 📈 Business Problem

Insurance companies generate large amounts of operational data from policy holders, policies, drivers, and claims.

Operational databases are optimized for transactions but are not suitable for analytical reporting.

This project transforms transactional insurance data into a structured analytical warehouse that supports business intelligence and strategic decision-making.

---

## 💼 Business Goals

- Monitor insurance claims
- Track claim amount trends
- Analyze policy performance
- Identify claim distribution
- Improve reporting efficiency
- Enable data-driven decisions
