# Data Dictionary

| Column | Data Type | Description |
|---------|-----------|-------------|
| claim_id | INT | Unique claim identifier |
| policy_id | INT | Insurance policy identifier |
| amount | DECIMAL | Claim amount |
| status | VARCHAR | Claim status |
| claim_type | VARCHAR | Insurance claim category |
| policy_holder_id | INT | Customer identifier |
| premium_amount | DECIMAL | Insurance premium |
| first_name | VARCHAR | Customer first name |
| last_name | VARCHAR | Customer last name |
| license_number | VARCHAR | Driver license number |
